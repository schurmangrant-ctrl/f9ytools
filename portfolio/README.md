# Grant Schurman — Architecture Portfolio

Static, no-build site. Open `index.html` or host the folder (GitHub Pages works).

- **Edit content:** `content.js` (name, links, projects). Replace every `TODO` URL.
- **Add images:** put files in `images/`, list them under a project's `images: []`.
  Projects without images show a generated plan drawing as a placeholder.
- **Résumé:** save your PDF as `resume.pdf` in this folder.
- Sections: `#/school`, `#/work`, `#/personal`; Résumé and Rosie's Home open externally.
